Data Custodian:
1. Data Storage 
2. Data Availability 
3. Data backup
4. Apply patches, configurations and updates 
5. Apply controls 
6. Control System access management 
7. System Maintenance 

Data Steward:
1. Ensure Data accuracy, quality and consistency 
2. Ensure compliance and apply governance 
3. MetaData definitions and dictionaries 
4. Works with business to maintain standards

1. Data Validity 
2. Data Integrity 
3. Data Audits 
4. Process new data
5. Perform quality checks
